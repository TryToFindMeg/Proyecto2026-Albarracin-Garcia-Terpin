# Fuente de RetroWave

Se incluye **DM Sans**, obtenida del [repositorio oficial de Google Fonts](https://github.com/google/fonts/tree/main/ofl/dmsans), con su licencia [SIL Open Font License](OFL.txt).

`DM-Sans.ttf` está disponible localmente para la etapa de CSS. Todavía no se aplica a la página. Al incorporar los estilos, se puede registrar mediante `@font-face` dentro del único archivo `css/estilos.css` y asignarla a los títulos o al contenido.
