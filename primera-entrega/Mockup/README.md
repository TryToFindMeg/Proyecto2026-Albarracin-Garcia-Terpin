# Mockup — pendiente de exportación

Existe un [prototipo en Canva](https://canva.link/nj6srhxjpvdix0j), con pantallas de escritorio y una variante estrecha de “Nosotros”.

La consigna exige guardar los diseños dentro del repositorio en **PNG, JPG o PDF**. El enlace de Canva por sí solo no cumple ese requisito y esta carpeta todavía no contiene las exportaciones.

## Archivos a incorporar

- Pantallas de escritorio: inicio, catálogos, detalle, carrito, cuenta y contacto.
- Versiones para celulares de las pantallas principales.
- Estados de error: campos obligatorios incompletos, email inválido, cantidad inválida y acceso incorrecto.
- Estado del carrito vacío y navegación entre pantallas.

Usar nombres descriptivos, por ejemplo `inicio-desktop.png`, `inicio-mobile.png` y `contacto-email-invalido.png`. No se debe confundir el diseño de un mensaje con su funcionamiento, que se implementará en JavaScript.
